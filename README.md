# PyMLFinance

PyMLFinance is a multi-page web application built using Python Dash.
It showcases Python, Machine Learning, and Finance courses through a clean UI.

## Features
- Multi-page routing
- Reusable navigation bar
- Course listing and detail pages
- Dash Bootstrap Components

## Tech Stack
- Python
- Dash
- Dash Bootstrap Components
